# XPut v1.9.0：SEO 补齐与统一内容管理

对应 Issue #47，承接定稿方案和 v1.8.1 审计。用户已确认：Search Console 尚未验证，先完成网站改造；投诉/删除申请在站内提交，现有后台统一处理。

## 行为

- Unix 秒、毫秒和 ISO 原帖时间均可评估；缺失时间不使用当前时间或保存时间冒充。
- 规则 v2 增加 80–159 内容单元的信息量分值 +20。有完整元数据、真实已保存媒体和可读结构的中等长度内容可达到 70 分；长文仍可单独通过。分数不代表 Google 评价，也不验证事实真伪。
- 启动时分批回填哈希，不改变未评估历史页面的收录状态。后台队列每分钟最多评估 20 条，仅管理已经评估/明确触发的记录；每日重评媒体及审核状态。规则版本变更自动重评。错误持久化，15 分钟后重试，最多 6 次，后台可重新触发。
- 原文标题规范为一个 H1，其余主标题保留为 H2；无标题时增加忠实原文的主题标题，保留正文、编号、媒体和翻译块。
- 本地图片使用实际文件尺寸，首图优先，其余懒加载；增加上下文 alt 和异步解码。外链统一 UGC/nofollow 属性。无真实尺寸的媒体不伪造宽高。
- 可见原帖时间和保存时间分开；SocialMediaPosting JSON-LD 保留真实作者、来源和时间，不将普通短帖冒充文章，不承诺富结果。
- 同作者的合格内容最多推荐 3 条；无相关记录时不随机推荐。首页保留最新/本机记录，增加合格精选内容导航；首批 SSR 记录直接交给客户端分页，避免加载时清空造成布局跳动。
- 首页主标题、分享图、使用步骤、FAQ 与投诉入口补齐。“浏览公开存档”位于说明标题右侧，移动端标题可自然换行。
- /report 为公开提交页（noindex），不是第二个后台。申请持久化，仅管理员接口可读；包含输入边界、来源校验和提交频率限制。
- /admin-xput.html 统一处理审核、存档删除、SEO 状态和投诉。支持分页、未评估/失败筛选；可以禁止收录并结案、直接结案，或明确确认删除后结案。禁止收录与删除访问含义明确分开。
- 新增固定名称转化事件 Archive start / Archive completed / Archive read / Browse archives / Translation requested；不上传提交链接、帖子正文或申请联系方式。

## 数据与运维

追加 seo_managed、seo_next_check、seo_attempts、seo_error 和 content_reports 表。既有已评估页面自动纳入重评；未评估历史内容不由定时任务自动扩量。投诉记录不随存档删除消失，便于核实处理；应限制后台访问并按业务保留政策清理历史联系信息。

首次发布前备份 SQLite，在服务器副本运行新规则只读预评估，抽查长文、中文/外文、媒体和重复边界后按 100 条串行 apply。哈希回填可独立运行，不开放收录：

```sh
DATA_DIR=/path/to/data SQLITE_PATH=/path/to/db.sqlite node ops/evaluate-seo.js --apply --hash-only --limit=100 --after-id=0
```

下一批使用返回的 lastId。常规预评估不使用 --apply；通过后常规 --apply 才写最终状态。

PUBLIC_BASE_URL 保持实际主域；未新增必填密钥。SEO_AUTO_INDEX=false 仍可暂停新推荐，但不是即时撤回所有已推荐页。www 暂不提供，主域、HTTP 和旧域名跳转沿用已验证策略，不添加错误的 hreflang 或虚假 lastmod。

回滚可恢复 v1.8.1 代码，保留追加字段和表；旧版不运行重评或处理投诉，但仍读取 SEO 最终状态。已有投诉和处理状态须保留。

## 验证与外部边界

- 自动测试覆盖时间兼容、评分可达性、哈希与历史放行分离、周期重评/失败重试、H1/媒体/编号保留、JSON 安全、公开申请与后台鉴权及处理。
- 隔离浏览器覆盖 1200px 桌面和 390px 手机布局、站内申请到既有后台结案与删除。
- `PUBLIC_BASE_URL=https://xput.app node ops/check-seo.js` 检查公开 robots、sitemap、HTTP、canonical、H1、JSON-LD。它不证明 Googlebot 访问或实际收录。
- 移动浏览器实验样本单独记录 LCP 与布局偏移；本次未获得 Lighthouse 分数。真实 Core Web Vitals 需实际访问数据，不能由实验结果替代。
- 用户已明确暂缓 Search Console：后续需验证域名、提交 https://xput.app/sitemap.xml、抽查规范 URL 和 4–8 周非品牌展示/点击。
- 保留历史统计 site ID；统计后台是否成功接收 xput.app 来源、事件目标配置和真实搜索转化，需要对应后台权限，不能单靠前端脚本确认。
