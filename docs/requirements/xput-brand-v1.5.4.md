# XPut v1.5.4 品牌更名与站内迁移需求

- 迭代版本：v1.5.4
- 基线版本：v1.5.3
- 日期：2026-09-26
- 状态：实施中
- GitHub Issue：https://github.com/wanXcode/xmirror/issues/13

## 背景与目标

域名迁移已经完成：xput.app 指向现有网站，xmirror.app 以 301 保留路径和查询参数跳转到新域名。本版将用户可见品牌从 XMirror 统一为 XPut，官网统一为 https://xput.app，保持已有内容和使用方式兼容。

## 确认的产品决定

1. 对外名称采用 XPut，域名采用小写 xput.app。
2. 更新首页、存档页面、中英文标题与说明、SEO、分享卡片、图标说明、安装名称、快捷指令使用说明和后台展示名。
3. 保留现有图形与页面布局，不增加业务功能。
4. 内部服务名、数据库、目录、健康检查标识和历史存储键继续使用 xmirror，避免破坏运维与数据兼容。
5. 保留旧域名及其证书续期能力，历史链接继续可用。

## 功能范围与验收标准

| 范围 | 需求 | 验收 |
| --- | --- | --- |
| 首页 | 标题、正文品牌、结构化数据和分享元信息为 XPut | 初次打开及中英文切换后都保持新品牌 |
| 存档页 | 页标题、品牌徽标、OG 站点名称为 XPut | 已有短码访问时动态显示新品牌，canonical 使用新域名 |
| 旧存档链接 | 保留 HTML 地址到短码的兼容映射 | 旧域名与旧 HTML 路径可到达对应内容 |
| 快捷指令 | 更新中英文卡片与使用说明，检查现有安装链接 | 可用安装链接继续展示；失效时提供可执行的手动配置说明，不展示不可用安装按钮 |
| 图标/安装 | SVG 可访问标题和 manifest 名称为 XPut | 图形不变；新添加到主屏幕使用新名称，旧快捷方式不会承诺自动更名 |
| 后台 | 可见品牌统一，保留认证方式 | 新域名需重新输入管理 Token；不迁移或暴露凭证 |
| 公开文档/演示页 | 当前入口、说明与演示品牌统一 | 历史变更记录允许出现旧名称；当前使用说明不指向旧域名 |
| 访问统计 | 沿用现有统计站点，保留历史数据 | 核验跟踪脚本与新域名事件；旧统计 ID 是内部兼容标识，不直接更换以免断档 |
| 版本 | package、lockfile、首页与版本文档统一 | 全部标记 v1.5.4，发布提交可追踪 |

## 兼容与风险

- 用户原文、历史媒体、数据库记录不做品牌字符串批量替换；避免改写用户内容。
- 浏览器存储按域名隔离，旧域名的后台登录信息不会自动带到新域名。
- 分享平台、浏览器图标和已安装主屏幕快捷方式可能缓存旧品牌，不能以服务端更新保证第三方立即刷新。
- 统计站点标识 data-domain="xmirror.app" 可作为历史数据兼容例外保留，并在代码中解释原因。

## 发布与回滚

独立分支开发，运行自动测试和页面核验，通过 GitHub PR/CI 后合并 main。服务器从 GitHub 拉取指定提交，以独立 worktree 执行 ops/deploy.sh，保留数据库快照和旧 release。公网验证首页、存档、旧域名 301 和 JSON/文本短链返回。

回滚只切换代码 release，不覆盖共享数据和媒体，保留已生效的新域名及旧域名 301 配置。
