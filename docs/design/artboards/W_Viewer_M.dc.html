Frequently asked questions

Can I view Twitter without logging in?−

Yes. Paste a link to any public post and tap View post to read the full text, photos and video. You don't need an X account, and you don't need to sign up for XPut either.

Is this Twitter viewer anonymous?−

Yes. XPut fetches the post for you, so neither the author nor X can see who viewed it. We don't ask you to log in and we don't keep a record of which posts you looked at.

What happens if the post is deleted?−

When you view a post on XPut, we save a copy. If the author later deletes the original, your XPut link still shows the saved version, along with the date it was saved.

Can I see deleted tweets?−

Only if the post was saved on XPut before it was deleted. XPut can't recover deleted tweets that were never viewed or saved here. If a post matters to you, view it on XPut while it's still online so a copy is kept.

Can I see someone's whole profile?−

No. XPut works with links to single posts only — there is no account search, profile browsing or timeline. If you paste a profile link, we'll ask you to paste a link to a specific post instead.

Can I see replies?−

We show how many replies a post has, but we don't load the replies themselves. Tap Open on X to read the full conversation there.
